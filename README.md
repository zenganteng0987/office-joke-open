# office-joke-open

Entry for [Make the AI Judge Laugh: the Office Joke Open](https://make.fun/bounty/u-aldy998-make-the-ai-judge-laugh-the-office-joke-open-9920f232) on make.fun. A tiny deterministic Node 22 / TypeScript program (`main.ts`) that writes a single line of office comedy — under 200 characters — to `/output/entry.txt`. The joke turns a blocked "focus time" calendar slot into a meeting about that very focus time.
